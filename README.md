A premium, mobile-first, Progressive Web App (PWA) designed to manage PG (Paying Guest) operations with high efficiency, automated receipts, and real-time inventory tracking.

---

## 🚀 Key Features

### 💎 Level 1: Core Foundation & Premium UI
- **Mobile-First Design:** Optimized for thumb-zone interaction and high-end mobile experience.
- **Smart Theme Engine:** Automatic Dark/Light mode synchronization with system preferences.
- **Interactive Dashboard:** Quick overview of revenue, pending rents, and active residents.

### 📊 Level 2: Financial Efficiency
- **Expense Tracker:** Categorized logging for Electricity, Water, Repairs, etc.
- **Net Profit Analysis:** Real-time calculation of `(Total Income - Total Expenses)`.
- **Payment Tracking:** One-tap "Mark as Paid" logic with overdue alerts.

### 🏨 Level 3: Inventory & Digitalization
- **Visual Room Map:** Interactive grid showing Room occupancy and Bed availability.
- **Automated PDF Receipts:** Instant, branded PDF generation for rent payments using `jsPDF`.
- **Document Management:** Digital storage for Tenant Photos and ID Proofs (Aadhar/PAN) via Firebase Storage.

### 📱 Level 4: Pro App Experience
- **PWA Integration:** "Add to Home Screen" support with a standalone, full-screen native app feel.
- **Multi-Step Onboarding:** A 3-step digital wizard for professional tenant registration.
- **Real-time Sync:** Live data updates across all devices powered by Firebase.

---

## 🛠 Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Vanilla CSS (Glassmorphism Design System)
- **Animations:** Framer Motion
- **Backend:** Firebase Firestore & Storage
- **Icons:** Lucide React
- **Reporting:** jsPDF & jsPDF-AutoTable

---

## 📦 Getting Started

1. **Clone the project**
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Set up Firebase:**
   Create a `.env` or update `config.js` with your Firebase credentials.
4. **Run development server:**
   ```bash
   npm run dev
   ```
5. **Access on Mobile:**
   Run `npm run dev -- --host` to expose the app on your local network.
